# 📝 Blog Website

A simple Full Stack Blog Website developed using **HTML, CSS, JavaScript, Node.js, and Express.js**. This project allows users to add, view, edit, and delete blog posts while demonstrating frontend and backend integration using REST APIs.

---

## 📌 Project Overview

This project was developed as part of a Full Stack Development internship. It demonstrates CRUD (Create, Read, Update, Delete) operations using Express.js and connects the frontend to the backend using the Fetch API.

---

## 🚀 Features

- 🏠 Home Page
- ➕ Add New Blog
- 📖 View All Blogs
- ✏️ Edit Existing Blogs
- 🗑️ Delete Blogs
- 🎨 Responsive User Interface
- ✨ CSS Animations & Hover Effects
- 🔄 Smooth Scrolling
- 📱 Mobile Responsive Design
- 🔗 Frontend & Backend Integration using Fetch API

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/koyyadakrithika-spec/website.git
```

### Go to the project folder

```bash
cd website
```

### Install dependencies

```bash
npm install
```

### Start the server

```bash
node server.js
```

```
http://localhost:3000
```

## 📡 API Endpoints

| Method | Endpoint | Description |
|---------|----------|-------------|
| GET | /blogs | View all blog posts |
| POST | /add-blog | Add a new blog |
| PUT | /edit-blog/:id | Update an existing blog |
| DELETE | /delete-blog/:id | Delete a blog |
